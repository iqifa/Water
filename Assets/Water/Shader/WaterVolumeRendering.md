# 水体体积渲染：散射与透射

> 适用文件：`Assets/Water/Shader/WaterVolumeLighting.hlsl`
> 使用方：`GerstnerWater.shader`、`SineWaterURP.shader`（同一套体积模型，统一渲染）

---

## 1. 物理背景：光在水里走两次

水不是普通透明材质，而是一种**参与介质**（Participating Medium）：光在水中传播时会被持续吸收和散射。一个人眼看到的水下像素，其光照路径是**双程**的：

```
太阳 ──去程──> 水底(或悬浮颗粒) ──返程(沿视线)──> 人眼
```

如果只算单程，水色会偏亮偏清；只算去程，水底会过暗。两个光程**各自独立衰减**，这是水体颜色的根本来源。

水中的两个光学过程：

| 过程 | 系数 | 作用 |
|------|------|------|
| **吸收 (Absorption)** | σ_a | 光能 → 热能，红光最先被吃掉（所以水下看东西偏蓝绿） |
| **散射 (Scattering)** | σ_s | 光改变方向：一部分射向人眼（让水"发亮"），一部分离开视线（让水"发浑"） |

**消光系数** = 两者之和：`σ_t = σ_a + σ_s`（单位 1/m）

## 2. 透射 (Transmittance)：比尔-朗伯定律

光在介质中走 L 米后的透过率：

$$T(\lambda) = e^{-\sigma_t(\lambda) \cdot L}$$

- 分通道计算：红光 σ 大先消失，蓝光 σ 小走得最远 → 深水偏蓝
- λ 就是 RGB 三个通道，用消光系数向量模拟光谱

### 双程拆分（本实现的核心）

**返程透过率**（水底 → 人眼）：

$$T_{view} = e^{-\sigma \cdot d_{view}}$$

`d_view` 是视线方向的水下距离（屏幕深度差直接可得）。

**去程透过率**（太阳 → 水底）：

$$T_{sun} = e^{-\sigma \cdot d_{sun}}, \quad d_{sun} = \frac{d_{vertical}}{\sin(\theta_{sun})}$$

太阳斜射入水时在水中走的路程比垂直水深长。θ_sun 越低（黄昏）光程越长，水底越暗越蓝——这个日变化是免费的物理效果。

**水底直射光**经历两次吸收：

$$T_{direct} = T_{sun} \cdot T_{view}$$

**环境光**从四面八方入水，平均光程比斜射短（取一半近似）：

$$T_{ambient} = e^{-\sigma \cdot d_{sun} \cdot 0.5} \cdot T_{view}$$

**最终透过率**按直射 70% / 环境 30% 加权：

$$T_{total} = lerp(T_{ambient},\ T_{direct},\ 0.7)$$

### 为什么不用单程模型

早期版本用 `d_optical = d_view + 0.35 · d_vertical` 混合光程，然后一次 exp。问题：

1. **物理含义模糊**：去程和返程的介质路径完全不同（去程方向随太阳变化，返程随视线变化），混在一个标量里无法单独调
2. **无法响应太阳高度**：单程模型里黄昏和正午水底一样亮，没有日照角度影响
3. **环境光被错误压暗**：混合光程把环境光的贡献也按全光程衰减，导致水体发黑（这正是当初“发黑问题”的根源）

双程模型把两个自由度拆开，每一项都有明确的物理对应，调参直觉：`_AbsorptionScale` 控清澈度，太阳角度自动影响水底亮度。

## 3. 内散射 (In-Scattering)：水为什么会"发亮"

消光只描述"光被吃掉"，但介质本身也会把光**散射进视线**——这就是水体本底色的来源。积分形式：

$$L_{in}(\lambda) = \int_0^{d_{view}} \sigma_s(\lambda) \cdot L_{light} \cdot P(\theta) \cdot e^{-\sigma_t \cdot s} \, ds$$

含义：视线沿途每个点都在接收光照并朝人眼散射，离人眼越远的点贡献被返程衰减越多。工程近似（见 `WaterVolumeShading`）：

- **积分近似**：不做逐段积分，用 `scatterMask = 1 - exp(-d_view / scale)` 作为"视线穿过了多少可散射介质"的权重
- **相位函数**：用 Henyey-Greenstein 相位函数 $P(\theta) = \frac{1-g^2}{4\pi(1+g^2-2g\cos\theta)^{1.5}}$ 描述散射方向分布——g>0 时前向散射增强，逆光看水时太阳方向的散射光直冲人眼，形成"翡翠透光"效果
- **去程吸收**：太阳分量乘 `exp(-σ · d_vertical·0.5 / sinθ)`，太阳光到达散射点前已被吸收一部分；环境分量去程更弱
- **阴影软化**：`shadowFactor = lerp(0.3, 1.0, shadow)` 只压 70%——体积散射本质是多次散射的累积，阴影边界本就模糊

## 4. 工程实现对照

### 4.1 消光系数：属性到物理量的映射

```hlsl
// _WaterAbsorptionColor 是"艺术家直觉"参数：你选的颜色 = 水染上的颜色。
// 物理上: 吸收率 = 1 - 颜色，平方拉开 RGB 差距 (红 0.85 -> σ_r 大, 蓝 0.12 -> σ_b 小)
float3 invColor = 1.0 - saturate(absorptionColor);
float3 extinction = (invColor * invColor * 2.5 + 0.02) × (1 / _AbsorptionScale)
```

- 平方映射：让高明度颜色(如 0.15,0.88,0.78)的 RGB 衰减率拉开差距，浅水染色更自然
- `+0.02` 保底：纯白(1,1,1)也有微弱吸收，避免 exp 恒等于 1（水体没有"零消光"）
- `_AbsorptionScale`：透过率 e^-1 的距离，即"清澈度"

### 4.2 水深重建

```hlsl
viewDepth     = LinearEyeDepth(scene) - surfaceEyeDepth      // 视线水下距离
verticalDepth = surfacePosWS.y - bottomPosWS.y               // 垂直水深 (重建水底世界坐标)
```

- `viewDepth` 用于返程（光沿视线走）
- `verticalDepth` 用于去程（光垂直入水深度）
两个深度缺一不可：斜视浅水时 viewDepth 大、verticalDepth 小 → 逆着光看浅水也会透出水底。

### 4.3 折射采样与防穿帮

折射偏移用 `normal.xz` 扰动 UV，两个安全措施（`WaterSampleRefraction`）：
1. **深度淡出**：水下物体太近时偏移衰减到 0（否则近处折射采样到水面上的东西）
- 2. **回退**：偏移后采到水面前方（viewDepth≤0）则回退到未偏移 UV

### 4.4 完整管线

```
场景颜色 (Opaque Texture, 折射 UV)
        │
        ▼
T_total (双程透过率) ──乘──> 水底透射色
        │                      │
        │                      ├──加──> 最终水体色
        ▼                      │
In-Scattering (HG相位+去程吸收+scatterMask) ──加──┘
```

## 5. 调参指南

| 参数 | 物理含义 | 调参效果 |
|------|---------|---------|
| `_WaterAbsorptionColor` | 水染上的颜色（其 RGB 反比于吸收率） | 选高明度青绿 → 清澈湖水；选深蓝 → 海洋 |
| `_AbsorptionScale` | 清澈度(米)，T=e^-1 的距离 | 8m 清澈湖泊；0.5m 泥潭 |
| `_WaterScatteringColor` | 水体内部本底色 | 决定深水颜色，不要选太暗 |
| `_ScatteringScale` | 散射亮度 | 调高水体内部透亮（翡翠感） |
| `_PhaseG` | HG 各向异性 0~0.9 | 调高逆光透光更强 |
| `_SunGlowIntensity` | 逆光透射强度 | 与 PhaseG 配合，调太高会过曝 |
| `_RefractionStrength` | 折射 UV 扰动 | 波浪扭曲水底影像 |
| `_RefractionFadeDepth` | 折射深度淡出 | 前景防穿帮距离 |

## 6. 已知近似与局限

- **多次散射**：真实水中光会被散射多次；本模型只用 HG 相位模拟单次前向散射的形状，环境光项粗略补偿
- **波面折射不弯折光线**：屏幕空间 UV 偏移是近似，大入射角时水底影像拉伸失真
- **垂直水深由屏幕深度反推**：坡度大的水底（墙壁入水处）verticalDepth 会有误差
- **单光源**：只算主光（太阳），无附加光源在水下散射的贡献
